# sofia-portfolio-orbit ✶

Personal site for [Sofia Grimm](https://www.sofiagrimm.com) — Yale '29, MCDB + Ethics, Politics & Economics.

A "daylight planetarium": pale periwinkle paper, space-ink type, and a hero where
research fields orbit as planets (neurons · proteins · galaxies · markets & policy).

## Stack
Plain HTML + CSS. No build step, no framework, no JavaScript required.
All content is server-rendered-by-default (i.e., it's just in the HTML), so it's
fully crawlable and works with JS disabled.

## Pages
- `index.html` — orbit hero, current work, highlights
- `about.html` — bio, at-a-glance facts, honors, toolkit
- `research.html` — full flight log with anchor links (`#higley`, `#fermilab`, …)
- `projects.html` — things built, all visible by default

## Fonts
[Fraunces](https://fonts.google.com/specimen/Fraunces) (display, with WONK on italics),
[Karla](https://fonts.google.com/specimen/Karla) (body),
[Space Mono](https://fonts.google.com/specimen/Space+Mono) (labels & coordinates).

## Deploy
Any static host. For GitHub Pages: Settings → Pages → deploy from `main` / root.
To use the custom domain, add a `CNAME` file containing `www.sofiagrimm.com` and
point DNS at GitHub Pages.
